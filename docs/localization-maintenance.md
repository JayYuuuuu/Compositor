2026-10-10 用户确认：独立名称 **Compositor CN**，与原版共存，使用社区独立更新源；先发布 **社区测试版**。首版基于上游 `v1.4.9`（标签提交 `0ab3ff58a3dcf3d52a455fe3ab0336ac95923edd`），社区标签 `v1.4.9-cn.1`，独立构建号 `10001`，后续构建号单调递增。版本与应用元数据见 `Config/CommunityRelease.json`。

更新源为本 fork 的 `appcast.xml`，使用独立 Ed25519 更新签名公钥。私钥仅保存在私有维护环境，不进入源码、应用包、命令行参数或日志。更新签名保护包的真实性，**不等于 Apple Developer ID 签名或公证**。首发为 ad-hoc 签名，未公证，macOS 可能阻止打开；安装说明与 Release 必须明确这一点。不得沿用上游“已签名、已公证”的分发说明。

继承的 `scripts/release.sh`、`scripts/publish.sh` 已封闭为拒绝执行的入口，防止误操作上游；正式构建和发布由私有维护服务执行，不在公开仓库存放发布凭证。发布目标固定为本 fork，更新包、校验值、源提交和实际验证结果需一致。

## 汉化机制与术语

使用 Apple 原生 `Localizable.xcstrings`，源语言 `en`、简体中文 `zh-Hans`。跟随 macOS 应用程序语言，切换后重新启动；没有新增应用内语言设置。英文保留作为回退，不翻译用户内容、文件名、字体名和内部标识。

首批覆盖菜单、工具栏、图层面板、常用弹窗和导入/导出；本次通过真实编译器提取补齐静态界面文字和独立更新弹窗，目前 **793 条双语资源**。部分高级工具的动态显示值和长操作提示仍可能为英文，不能把资源条数等同于全界面完全汉化。

混合模式使用未翻译的关联值识别，预览、选择和状态同步不解析菜单标题。命令菜单 ID 与当前显示语言分离，执行前校验动作、快捷键、可用性和位置；命令搜索支持当前界面语言。动态撤销/重做使用完整可翻译句子，历史不写入项目文件。快捷键定义的英文标识保持固定，不能因显示翻译而改变。

同类功能优先沿用 Photoshop 简体中文常用术语，参考 [Adobe 官方混合模式说明](https://helpx.adobe.com/cn/photoshop/desktop/repair-retouch/adjust-light-tone/blending-mode-descriptions.html)、[剪贴蒙版说明](https://helpx.adobe.com/cn/photoshop/using/revealing-layers-clipping-masks.html)和[图层蒙版说明](https://helpx.adobe.com/cn/photoshop/using/editing-layer-masks.html)。专业译者人设只是方向，固定术语、上下文、占位符/快捷键校验与语义复核共同保证质量；例如混合模式 `Screen` 是“滤色”，显示器语境则是“屏幕”。

## 私有自动维护

用户确认后，后续跟进、翻译和发布的实现、术语规则与详细评测记录迁入私有维护后台。公开仓库只承载应用源码、资源、必要文档/验证和安装包。之前公开推送的脚本与规则仍可在 Git 历史中找到；没有强推或清除历史，凭证从未公开。

维护服务按上游**正式发布标签**取源码，不跟随尚未发布的每次 main 提交。在隔离目录合并、原生提取新增文字、保留已有译文、调用 DeepSeek 增量翻译、校验、运行 Mac 测试、构建社区包、签名独立更新源并发布。冲突、翻译不确定、校验失败、构建或界面测试失败时停止；同一未修复失败源不反复调用模型。无新版本不翻译、不构建。运行状态要区分未变化、运行中、需处理和已发布，不能仅以调度器退出码证明发布完成。

公开的 Verify 工作流不持有翻译或更新私钥；维护服务可触发指定源提交的云端 Mac 全量单元测试和中英文真实界面验证。发布前确认验证源提交、包内身份和版本、更新来源、包 SHA-256 与预备产物一致；仅在验证通过后将草稿版本公开。

实际调度、私有配置、失败恢复与运行记录由私有交接文档维护。公开仓库中有未跟踪的 `CLAUDE.local.md` 时，维护者可据此定位；不得把机器地址、私有路径、账号凭据、日志或私钥提交到公开仓库。
